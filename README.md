# Saturnalia App

Welcome to the Saturnalia App! This application allows users to discover upcoming events, view event details including location on a map, register for events, and generate QR codes for validation at event venues. Additionally, administrators have access to features such as adding new events, editing event details, updating event locations, and scanning QR codes for attendee validation.

## Getting Started

To get started with the Saturnalia App, follow these steps:

1. Clone the repository to your local machine:

```
git clone https://github.com/AyushKrSingh000/saturnalia-app.git
```

2. Navigate to the project directory:

```
cd saturnalia-app
```

3. Install the necessary dependencies:

```
flutter pub get
```

4. Run the app:

```
flutter run
```

## Features

### User Features

1. **View Upcoming Events**: Users can browse and view a list of upcoming events with details like event name, date, and location.

2. **Event Location on Map**: Users can see the event location on a map, making it easier to find and navigate to the venue.

3. **Event Registration**: Users can register for events they are interested in attending. After registration, a QR code is generated for each event.

4. **QR Code Validation**: At the event venue, users can present their generated QR code for validation, allowing easy and secure access.

### Admin Features

1. **Admin Login**: Administrators can access admin features by logging in with admin credentials.

2. **Add New Event**: Admins can add new events to the system, providing details such as event name, date, location, and description.

3. **Edit Event Details**: Admins can edit event details, including updating event information, date, and location.

4. **Update Event Location**: Administrators have the ability to change the event location as needed.

5. **QR Code Validation**: Admins can use the app to scan QR codes at the venue to validate attendee registrations.

## Usage

1. **User Registration**:

- Users can register in the app using their email or social media accounts.

2. **View Upcoming Events**:

- Browse and explore the list of upcoming events.
- Click on an event to view more details.

3. **Event Registration**:

- Register for events you wish to attend.
- A unique QR code will be generated for each registered event.

4. **Event Validation**:

- Show your generated QR code at the event venue for validation.
